# Fiche de Kaya — version artistique 1

Générée le 25 octobre 2026 avec l’outil intégré `image_gen`, à partir de
`docs/design/cartes-ia/images/exploit-premiere-lecon-source-v1.png`.
Fichier livré : `kaya-turnaround-v1.png` (face, trois quarts, profil, dos).
Cette fiche est une référence artistique ; elle ne constitue ni un maillage ni
un rig. Elle reste hors du paquet du jeu.

La fiche conserve la tête ronde et large, les yeux ambrés, les oreilles sombres,
le petit museau crème, le nez corail, les pattes potelées et la queue entière.
Les rosettes irrégulières doivent être peintes sur le modèle plutôt qu’ajoutées
comme des pastilles en relief. Les quatre vues sont une base de cohérence ; leur
topologie, le détail des marques et les performances demandent un contrôle sur
le modèle construit et dans le parcours réel.
