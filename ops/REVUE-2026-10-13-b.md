### 6. [MOYENNE] Service worker : aucune requête `Range` gérée — la voix humaine (et les voyelles) risque de ne jamais jouer sur iPad/iPhone (Safari), sans message
- Fichier : `sw.js:390-408` (`respondWith(cache.match(req, { ignoreSearch: true }))` renvoie toujours le fichier entier en 200), lecteur `js/services/voice.js:165-183` (`new Audio(url)`, repli silencieux sur la synthèse quand `onerror`).
- Vérifié (Chromium, SW actif) : `fetch('audio/mots/chat.mp3', { headers: { Range: 'bytes=0-1' } })` → **200**, 3168 octets, sans `Content-Range` (un serveur correct répondrait 206, 2 octets).
  Chrome s'en accommode ; Safari/WebKit (AVFoundation) sonde les médias par `Range` et refuse une réponse de service worker qui n'est pas en 206 : c'est la raison d'être du module « range requests » de Workbox. **À vérifier sur un vrai iPad** (la liste d'essais B4.4 du rapport mobile n'a pas été faite).
  Si c'est confirmé : sur iPad/iPhone (Ajouter à l'écran d'accueil — le chemin iOS décrit dans `twa/README.md`), les 268 mots et 11 voyelles échouent, `playFile` résout `false` et Kaya retombe sur la synthèse, sans erreur visible : la fonction phare « vraie voix humaine » disparaît sans que personne le sache.
- Correction proposée (testée sous Node avec `Response`/`Request`) :

```js
// sw.js — avant le gestionnaire « fetch »
async function withRange(req, hit) {
  const m = /^bytes=(\d*)-(\d*)$/.exec(req.headers.get('range') || '');
  if (!m || !hit) return hit;
  const buf = await hit.arrayBuffer();
  const size = buf.byteLength;
  const start = m[1] === '' ? Math.max(0, size - Number(m[2])) : Number(m[1]);
  const end = m[1] === '' || m[2] === '' ? size - 1 : Math.min(Number(m[2]), size - 1);
  if (!(start <= end && start < size)) return new Response(null, { status: 416, headers: { 'Content-Range': `bytes */${size}` } });
  return new Response(buf.slice(start, end + 1), { status: 206, statusText: 'Partial Content', headers: {
    'Content-Type': hit.headers.get('Content-Type') || 'audio/mpeg', 'Content-Range': `bytes ${start}-${end}/${size}`,
    'Content-Length': String(end - start + 1), 'Accept-Ranges': 'bytes' } });
}
// dans le gestionnaire : « if (hit) return withRange(req, hit); »   (au lieu de « if (hit) return hit; »)
```
